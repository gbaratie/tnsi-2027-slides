# TNSI — Supports de cours 2027

Ce dépôt public contient les supports projetables du cours **Transition Numérique des Systèmes d'Information**, ainsi que les decks guidés des TP.

**TNSI** est le nom court du portail. Pour l’ajouter à l’écran d’accueil : Safari → Partager → Sur l’écran d’accueil sur iOS ; menu du navigateur → Installer / Ajouter à l’écran d’accueil sur Android, selon les options proposées. L’icône utilise une image originale générée pour le projet, déclinée en formats Apple, Android et navigateur ; le bleu et le blason rappellent Dauphine–PSL, tandis que les connexions évoquent l’innovation numérique.

Les anciens raccourcis web peuvent conserver leur icône en cache : les retirer puis ajouter à nouveau le site après sa mise à jour. Pour un raccourci de l’app Raccourcis ayant une image personnalisée, modifier cette image dans l’app. Le manifeste décrit l’identité et le lancement ; il n’ajoute pas de cache hors ligne.

Consulter les supports sur **[gbaratie.github.io/tnsi-2027-slides](https://gbaratie.github.io/tnsi-2027-slides/)**.

Ce dépôt est généré automatiquement depuis la source du cours. Les contributions et corrections doivent être réalisées dans le dépôt source ; une modification directe de ce miroir pourra être remplacée lors de la synchronisation suivante.

Les corrections enseignant, données internes et outils de construction ne sont jamais publiés ici.
