Dans le dépôtrepo/
├─ .github/workflows/
│ └─ deploy.yml
├─ deployment.yaml

Un format de texte.
Plusieurs schémas et lecteurs.

deploy.yml

Les étapes du pipeline.
Lu par GitHub Actions.

deployment.yaml

L’état souhaité de l’application.
Transmis à l’API Kubernetes.

render.yaml

Les ressources d’une plateforme.
Lu par Render.

Le fichier décrit ; l’outil interprète et agit. Un YAML présent dans Git ne déploie rien à lui seul.
